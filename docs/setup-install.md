# Setup And Install

## Requirements

- macOS 14 or newer.
- Xcode command line tools or a full Xcode installation with SwiftPM available.

## Local Workflow

```sh
make setup
make build
make run
```

`make run` builds the SwiftPM executable, stages `dist/ClipboardMarkup.app`, and launches the app bundle with normal foreground activation.

## Analytics Config

Usage analytics are privacy-safe and can be disabled from Settings > Other. Trusted builds read `CLIPBOARD_MARKUP_ANALYTICS_BASE_URL`, `CLIPBOARD_MARKUP_ANALYTICS_KEY_ID`, `CLIPBOARD_MARKUP_ANALYTICS_SECRET`, and optional `CLIPBOARD_MARKUP_ANALYTICS_AUDIENCE` environment variables. Run `make analytics-config` to validate those values and write the ignored, mode-0600 `Config/AnalyticsConfig.local.plist`; `make run` and `make verify` copy that file into the staged app bundle when present. Builds without a local or Application Support config keep analytics disabled.

The GitHub repository stores the first three values as Actions secrets with those same names. The app checks for an Application Support override at `~/Library/Application Support/ClipboardMarkup/AnalyticsConfig.plist`, then the bundled plist, and finally the environment variables. `Config/AnalyticsConfig.example.plist` documents the plist shape. Because a bundled client credential can be extracted, it must remain namespace-scoped and rotatable rather than granting administrative access.

Analytics events never include clipboard contents, OCR text, clip titles, search queries, file paths, media filenames, or password-manager contents. The durable analytics queue lives locally under Application Support and is separate from the movable clipboard-history data directory.

## Developer Diagnostics

Debug builds show a Settings > Debug tab with analytics status, configuration metadata, queued events, retry state, and recently synced batches. Release builds can show the same tab for local troubleshooting by setting `CLIPBOARD_MARKUP_DEVELOPER_MODE=1` before launch or by enabling the `ClipboardMarkupDeveloperModeEnabled` user default.

## Verification

```sh
make verify
make test
```

The app uses `Control` + `Option` + `C` as its default global shortcut. If another app owns that shortcut, the app still runs, and Settings shows that the shortcut is not registered until the conflict is removed or the shortcut is changed.

Use `Command` + `+` and `Command` + `-` to change app text size. Use `Command` + `0` to reset text size to 100%. Settings > Appearance can follow the system appearance or force Clipboard Markup to Light or Dark mode.

Open Settings to resize sidebar image thumbnails up to 300 pt. The sidebar can be dragged wider when using larger thumbnails. Image thumbnails show the full screenshot plus a centered 1:1 magnifying-glass lens while the thumbnail is below 50% scale. Image clip names start with the existing dimension-based fallback, then update from local text transcription when OCR finds readable text; editing the title in the detail header creates a manual name that takes precedence.

Settings > Other includes a Startup toggle for launching Clipboard Markup after you sign in. When enabled, macOS starts a bundled login launcher, which opens Clipboard Markup quietly in the menu bar so clipboard capture resumes without showing the main window. This starts after user login; it does not capture before login or after the app has been force-quit.

Text clips use stacked rows with a bordered snippet tile. The tile uses the same preview-height setting and truncates overflowing copied text.

Clipboard Markup skips pasteboard contents that declare common macOS concealed, transient, autogenerated, or legacy password marker types, plus known password-manager source identifiers such as 1Password, Bitwarden, KeePassXC, LastPass, Dashlane, Keeper, Enpass, Proton Pass, and KeeWeb. Browser extensions or apps that copy secrets without those markers may still appear as normal text.

Use the compact icon-only filter menu at the top-right of the sidebar to switch between Images, Text, All Clips, Favorites, and Deleted Items. The filter defaults to Images. Click the magnifying-glass search control beside it, or press `Command-F`, to expand sidebar search, which filters the selected view by clip name, copied text content, or image OCR transcript.

The app persists the current sidebar filter and selected clip between launches. Appearance theme, text size, thumbnail size, and the global shortcut are also persisted in user defaults.

Select a history entry and press Delete/Backspace while the list is focused to move it to Deleted Items. The detail header also has a trash icon for deleting the selected entry. Deleted Items rows and details expose Restore; deleted entries are permanently purged after 30 days.

Settings includes Storage Location and Other tabs. By default, the app writes an `AGENTS.md` guide into `~/Library/Application Support/ClipboardMarkup`. Storage Location shows each available data directory option with an Open in Finder button and can migrate the data directory to iCloud Drive, Dropbox, Google Drive, or any custom folder; this copies `entries.json`, `AGENTS.md`, and the media directory to the selected location and uses that folder for future captures. If macOS denies write access to a provider folder, the app asks you to allow access and retries the migration. Other provides the launch-at-login toggle, usage analytics opt-out, a copyable prompt snippet that points agents at the generated guide, and a confirmed Clear Clipboard History action that permanently deletes captured history and media while leaving app preferences, analytics queue state, and the current system clipboard unchanged.

New clipboard captures are selected automatically. If the current filter or search would hide the new capture, the app switches to the matching item-kind filter and clears search.
