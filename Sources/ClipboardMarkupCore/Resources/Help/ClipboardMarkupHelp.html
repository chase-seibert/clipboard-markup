Clipboard Markup Help

Clipboard Markup keeps a local history of copied text, rich text, images, and screenshots so you can return to recent clips quickly.

Shortcuts

  • Command-C copies the selected clip's preferred representation.
  • Option-Command-C copies plain text for rich text clips or the original image for image clips.
  • Command-E opens markup for image clips.
  • Space opens Quick Look.
  • Command-Return renames the selected clip when the clip list is focused.
  • Delete moves the selected clip to Deleted Items when the clip list is focused.
  • Command-D toggles Favorite.
  • Command-1 through Command-5 switch filters.
  • Command-F opens search.

Filters And Search

Use the filter menu in the sidebar to show all clips, images, text, favorites, or deleted items. Search checks names, copied text, and image OCR summaries.

Markup

Image markup supports arrows, rectangles, and text. Select existing markup to move, resize, restyle, or delete it before saving. Saving bakes the marked-up image while keeping the original image available.

Appearance

The Appearance tab in Settings can follow the system appearance or force Clipboard Markup to Light or Dark mode. It also controls app text size and sidebar thumbnail size.

Startup

The Other tab in Settings can launch Clipboard Markup after you sign in. Startup launches quietly in the menu bar so capture resumes without opening the main window.

Data Storage

Clipboard history is stored as an entries.json manifest plus media files. By default this lives in Application Support. The Storage Location tab in Settings can move it to iCloud Drive, Dropbox, Google Drive, or a custom folder for cloud-provider syncing, and the Other tab includes the agent prompt snippet.

Usage Analytics

The Other tab in Settings includes a privacy-safe usage analytics toggle. Analytics can report app/session activity, clip types, major feature actions, filters, search usage, settings sections, and storage-provider categories.

Analytics configuration is supplied by a local AnalyticsConfig.plist. Events are uploaded as signed gzipped batches and retried from a local Application Support queue when the network or server is unavailable.

Privacy

Clipboard Markup stores clipboard data locally. It skips common password-manager clipboard payloads where possible and keeps your current system clipboard separate from the app history clear action. Analytics never includes clipboard contents, OCR text, clip titles, search queries, file paths, media filenames, or password-manager contents.
